
# Module Git

## Опис проєкту
Цей проєкт створений для вивчення основ роботи з Git, GitHub та організації структури Python-проєктів.

## Структура проєкту

- `src/` — основні файли програми.
- `tests/` — файли для тестування.
- `books/` — файли з інформацією про книги.
- `config/` — файли налаштувань проєкту.
- `main.py` — головний файл проєкту.
- `.gitignore` — список файлів і папок, які Git повинен ігнорувати.

## Технології
- Python
- Git
- GitHub
- JSON

## Мета проєкту
Навчитися створювати структуру Python-проєкту, працювати з терміналом та використовувати систему контролю версій Git.
